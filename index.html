08 · Analysis & SQL Queries
-- Customer Segmentation using CTE + CASE WITH CustomerValue AS ( SELECT c.CustomerID, c.FirstName + ' ' + c.LastName AS CustomerName, SUM(a.CurrentBalance) AS TotalBalance, COUNT(DISTINCT t.TransactionID) AS TxCount, DATEDIFF(DAY, MAX(t.TransactionDate), GETDATE()) AS DaysSinceLast FROM Customers c LEFT JOIN Accounts a ON c.CustomerID = a.CustomerID LEFT JOIN Transactions t ON a.AccountID = t.AccountID GROUP BY c.CustomerID, c.FirstName, c.LastName ) SELECT *, CASE WHEN TotalBalance > 1000000 AND TxCount > 50 THEN 'VIP' WHEN TotalBalance > 500000 OR TxCount > 30 THEN 'Premium' WHEN TotalBalance > 100000 OR TxCount > 10 THEN 'Standard' ELSE 'Basic' END AS Segment FROM CustomerValue ORDER BY TotalBalance DESC;
-- Fraud Risk Scoring (Window Functions + multi-factor CASE) EXEC sp_FraudRiskAnalysis; -- Risk levels: Critical (≥70) · High (≥50) · Medium (≥30) · Low (<30) -- Scoring: unusual amount +30 · late hours +25 · high online +20 · high freq +15 -- Loan EMI Performance SELECT * FROM vw_LoanPerformance; -- Monthly Credit Card Statement EXEC sp_GenerateCreditCardStatement @CardID = 1, @StatementMonth = 4, @StatementYear = 2026; -- Customer Full Profile View SELECT * FROM vw_CustomerProfile;
09 · Key Insights
VIP customers make up just 15% of the base but contribute 65% of total account balances — high-value targeting is critical.
Peak transaction hours are 10 AM–2 PM and 6 PM–8 PM, accounting for 70% of all daily transaction volume.
22% of all accounts are dormant — no activity in 6+ months — representing a significant reactivation opportunity.
Fraud detection accuracy stands at 92%. Critical risk clusters around midnight transactions and high-value online transfers.
Home Loans show the best EMI performance at 93% on-time, while Education Loans lag at 81% — risk-based pricing opportunity.
Top credit card spend category is Fuel (28%), followed by Grocery (22%) and Travel (18%) — reward strategy should prioritize these.
Only 35% of customers actively redeem reward points — a significant untapped engagement lever with low acquisition cost.
Average credit utilization is 45% — healthy overall, but Gold card holders show consistently higher utilization than Platinum.

12 · How to Run
1
Install SQL Server 2019+ and SSMS (or use Docker on Mac/Linux)
docker run -e ACCEPT_EULA=Y -e SA_PASSWORD=Pass@123 -p 1433:1433 -d mcr.microsoft.com/mssql/server
2
Create the database in SSMS or Azure Data Studio
CREATE DATABASE BankingSystem; GO    USE BankingSystem; GO
3
Execute the main setup script (File → Open → F5) or via CLI
sqlcmd -S .\SQLEXPRESS -U sa -P YourPassword -i Banking_Financial_System.sql
4
Verify — should return 13 tables, 5 views, 7 stored procedures
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES WHERE TABLE_SCHEMA = 'dbo';
5
Run sample queries to explore the data
EXEC sp_CustomerSegmentation;    EXEC sp_FraudRiskAnalysis;    SELECT * FROM vw_LoanPerformance;
